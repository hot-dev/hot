Org API keys

An org API key manages child organizations, their environments and API keys through /v1/orgs and /v1/api-keys. It cannot call runtime routes: environment API keys and service keys stay bound to one environment. org:* means this organization's children, never this organization itself; grant org:{{ root.org_id }}/… explicitly for that.

Grants inside an environment, such as org:*/env:*/event:*, only set the ceiling for environment keys this key creates. Creating more org keys needs org:{{ root.org_id }}/api-key:* with create.
