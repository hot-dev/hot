Using an org key

Send the key in the Authorization header. It works on /v1/orgs and /v1/api-keys:

curl -H "Authorization: Bearer YOUR_ORG_KEY" \
     {{ page_context.api_url }}/v1/orgs

To call a sub-organization's environment, use the org key to create an environment key there, and call the API with that. Manage sub-organizations on the Sub-orgs page.
